# Contributing

Issues and pull requests are welcome. For a bug, report the platform, OS, runtime versions, model/backend, reproduction steps and a minimal sanitized log. Keep credentials, private videos, session profiles, runtime binaries and weights out of Git.

Before submitting code, run the native and Python tests via the documented CMake presets. Preserve model-specific vector semantics, evidence references and timestamp behavior. Label simulated results as simulated; for device performance changes, include hardware/software versions, workload, metric definitions and the number of trials.

Please keep changes focused and explain any runtime or asset-license implications. Do not submit code or assets you lack permission to distribute.
